# 🎭 얼굴 인식 분류 프로젝트 (260108)
카메라 또는 이미지 데이터를 활용하여 특정 인물의 얼굴을 인식하고 분류하는 파이썬 기반 딥러닝 프로젝트입니다.

Note: 현재 배우 '이동욱'의 데이터를 기본으로 하고 있으나, image/ 폴더 내의 사진을 교체하는 것만으로 원하는 인물의 분석 모델을 커스텀 생성할 수 있습니다.

## 🛠 주요 기능
* **얼굴 데이터 수집**: `get_face.py`를 통해 일반 사진에서 얼굴 데이터를 추출합니다.
* **데이터 로딩 및 전처리**: `load_data.py`를 사용하여 수집된 데이터를 학습 가능하게 가공합니다.
* **모델 학습**: CNN 기반 모델을 사용하여 얼굴을 분류하는 모델을 생성합니다.
* **예측**: 학습된 모델을 통해 실시간으로 얼굴을 판별합니다.

## 📂 프로젝트 구조
* `main.py`: 프로젝트의 전체 실행 흐름을 제어하는 메인 파일입니다.
* `get_face.py`: 일반 사진에서 얼굴 이미지 수집을 담당합니다.
* `image/`: 학습 및 테스트에 사용되는 이미지 데이터가 저장되는 폴더입니다.
* `*.keras`: 학습이 완료된 딥러닝 모델 파일들입니다.
